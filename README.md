# ZYVERON Bot v5
Aiogram 3.x business bot with RU/LV/EN, persistent SQLite, client forms, contact notifications and Telegram admin panel.

## Render
Set BOT_TOKEN and ADMIN_ID. Persistent Disk is configured in render.yaml.
## Logo
Place the ZYVERON logo at `media/logo.jpg` or set LOGO_PATH to another image path.
